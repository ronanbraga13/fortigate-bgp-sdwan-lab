Antes de adicionar arquivos, remover endereços de gerenciamento, credenciais, identificadores sensíveis, barras do navegador e metadados inadequados. Verificar visualmente a imagem final; ocultar conteúdo apenas com uma camada editável não garante remoção.

Não usar imagens ilustrativas como evidência de testes reais.
